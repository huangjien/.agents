# Skills-first 重构 ~/.agents hub

## 目标架构（三层）

```
Layer 0  常驻标准   AGENTS.md Part 1+2（工程与安全契约，不动）
Layer 1  按需知识   skills —— 默认派发目标，加载进当前上下文（progressive disclosure）
Layer 2  派生计算   仅 2 个 spawn 角色 —— researcher（隔离噪音大的搜索）、reviewer（无锚定的新上下文验证）
```

派发规则改为：**默认加载 skill 就地执行；仅当满足 spawn 条件时才派生**（全新上下文验证 / 大范围扇出搜索 / 用户点名要 agent）。STYLE.md 的 "Agents first" 原则（工件服务 agent 读者）与派发机制无关，原样保留。

数据依据：7 个 subagent 文件平均 ~70% 知识 / ~14% 与 AGENTS.md 重复的政策 / ~21% 派生逻辑；tier hints 从未生效（全部 model: inherit）；流程知识已被 `diagnose`/`code-review`/`tdd`/`doc-coauthoring` 覆盖，缺的是 15 项表格/清单类硬知识。
