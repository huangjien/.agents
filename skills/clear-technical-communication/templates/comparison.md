# Template: Comparison

> **Use when:** the user asks "A vs B" or "which should I pick" or "compare
> these options". This template keeps the table from becoming a wall and
> forces the takeaway to live at the top and bottom.

---

## TL;DR recommendation

One paragraph. State the choice (or "it depends, here's how to decide")
and the 2–3 most important trade-offs that drive it. The reader who only
reads this should still get the gist.

## Decision at a glance

| **Lock-in** | low / med / high | | |

| **Reversibility** | one sentence | | |

Pick comparable rows. If two rows aren't comparable on the same axis, drop
one of them rather than fudge the comparison.

## Recommendation

Repeat the TL;DR with more nuance. State the precondition that would
flip your recommendation ("If your workload is X, instead use Y"). Name
the one question that would change the call.

## Open questions

Bullets. What you'd need to know to firm up the recommendation.
